## 1. Pandas – Time Series Data

Learn how to work with dates and time-indexed data, summarize observations over time, and calculate rolling statistics.

### Topics

- Create date ranges using `pd.date_range()` and convert values using `pd.to_datetime()`.
- Extract date components such as year, month, day, and weekday.
- Set a datetime index and select data for particular dates or months.
- Resample time series data and calculate aggregate statistics.
- Calculate rolling averages using `rolling()`.
- Explore lagged values and changes using `shift()` and `diff()`.
