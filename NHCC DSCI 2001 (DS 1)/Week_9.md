## 1. Pandas – Split, Apply, and Combine

Learn how to split a dataset into groups, apply calculations to each group, and combine the results into meaningful summaries using pandas.

### Topics

- Understand the **Split–Apply–Combine** workflow.
- Group data by one or more columns using `groupby()`.
- Calculate group-level summaries using aggregate functions.
- Create pivot tables using `pivot_table()` and compare them with `groupby()` results.
- Explore group operations using `apply()`, `transform()`, and `filter()`.
