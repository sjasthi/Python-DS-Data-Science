Lists

A list holds items in order, and you can change it whenever you like. Reach for a list when you have a collection that will grow, shrink, or be re-sorted.

  • Ordered
  • Duplicates allowed
  • Changeable
  • [ ]

Create and access

Indexes start at 0. Negative indexes count from the end, so -1 is the last item. A list can mix data types.

fruits = ['apple', 'banana', 'cherry']
mixed  = ['alex', 17, 100.56]

print(fruits[0])       # apple
print(fruits[-1])      # cherry
fruits[1] = 'blueberry'
print(fruits)          # ['apple', 'blueberry', 'cherry']
print(len(fruits))     # 3

Methods you need to know

You must have a list to call these methods, as in my_list.append(4).

Removeremove(x)Removes the first item equal to x

nums = [3, 1, 2]
nums.append(4)          # [3, 1, 2, 4]
nums.extend([5, 6])     # [3, 1, 2, 4, 5, 6]
nums.insert(0, 9)       # [9, 3, 1, 2, 4, 5, 6]
nums.remove(9)          # [3, 1, 2, 4, 5, 6]
last = nums.pop()       # last is 6, nums is [3, 1, 2, 4, 5]
nums.sort()             # [1, 2, 3, 4, 5]
nums.reverse()          # [5, 4, 3, 2, 1]
print(nums.index(3))    # 2
print(nums.count(3))    # 1

Slicing: [start : stop : step]

Three ways to loop

colors = ['red', 'green', 'blue']

for i in range(len(colors)):        # you care about the index
    print(i, colors[i])

for c in colors:                    # you care about the values
    print(c)

for i, c in enumerate(colors):      # you care about both
    print(i, c)

List comprehension

Build a new list from an existing one in a single line. The if condition is optional.

[output for item in collection if condition]

[x + 1 for x in range(10) if x % 2 == 0]   # [1, 3, 5, 7, 9]
[n * n for n in range(1, 6)]               # [1, 4, 9, 16, 25]

Map, filter, reduce

IdeaMeaningExample with nums = [1, 2, 3, 4]
MapTurn each value into something else[x * 2 for x in nums] gives [2, 4, 6, 8]
FilterKeep only some items[x for x in nums if x > 2] gives [3, 4]
ReduceSummarize to one valuesum(nums) is 10, max(nums) is 4, len(nums) is 4

Unpacking

my_list = ['red', 'green', 'blue', 'black']
c1, c2, c3, c4 = my_list          # one variable per item
c1, *c2, cx = my_list             # c1='red', c2=['green','blue'], cx='black'

print(my_list)                    # ['red', 'green', 'blue', 'black']
print(*my_list)                   # red green blue black

Nested and 2-D lists

grid = [[1, 2, 3],
        [4, 5, 6]]
print(grid[1][2])       # 6  (row 1, column 2)

for row in grid:        # row-major traversal
    for value in row:
        print(value)

Copying: same remote, or a new TV?

nums_1 = [3, 4, 5]
nums_2 = nums_1            # NOT a copy: both names point to the same list
nums_2.append(6)
print(nums_1)              # [3, 4, 5, 6]

nums_3 = nums_1.copy()     # a new, independent list
nums_4 = nums_1[:]         # also a new list (slice copy)
Watch out: nums_2 = nums_1 gives you a second name for the same list, not a second list. Use .copy() or [:] when you want a separate one.

Tuples

A tuple is a list that can't be changed. Use one for data that should stay fixed, such as a point on a graph or a date.

  • Ordered
  • Duplicates allowed
  • Changeable
  • ( )

Create and access

point = (3, 4)
colors = ('red', 'green', 'red')

print(point[0])        # 3
print(colors[-1])      # red
print(len(colors))     # 3

point[0] = 9           # TypeError: 'tuple' object does not support item assignment

The one-item tuple needs a comma

a = (10,)      # a tuple with one item
b = (10)       # just the integer 10 in parentheses

print(type(a))   # <class 'tuple'>
print(type(b))   # <class 'int'>
Watch out: The comma makes the tuple, not the parentheses. Forget it and Python gives you a plain number.

Only two methods

Tuples can't change, so anything that adds, removes, or reorders items is missing. Only these two are left:

MethodWhat it doesExample with t = (1, 2, 2, 3)
count(x)How many times x appearst.count(2) gives 2
index(x)Position of the first xt.index(3) gives 3

Adding tuples makes a new tuple

a = (1,)
a = a + a          # (1, 1)  a brand-new tuple; the old one is untouched
b = (1, 2) + (3,)  # (1, 2, 3)

Unpacking and swapping

point = (3, 4)
x, y = point            # x is 3, y is 4

x, y = y, x             # swap two values in one line
print(x, y)             # 4 3

Why use a tuple instead of a list?

Safety. Nobody can change the data by accident, which is useful for fixed values like (1920, 1080).
Dictionary keys. Tuples are immutable, so they can be dictionary keys. Lists can't: {(0, 0): 'origin'} works.

Sets

A set keeps only unique items and has no order. It's the right tool for removing duplicates and for asking "what do these two groups share?"

  • Ordered
  • Indexed
  • Duplicates
  • Add and remove items
  • { }

Create a set

colors = {'red', 'green', 'red', 'blue'}
print(len(colors))       # 3  (the extra 'red' is dropped)

empty = set()            # an empty set
oops  = {}               # this is an empty DICTIONARY, not a set

print('red' in colors)   # True
print(colors[0])         # TypeError: sets have no index
Watch out: Use set() for an empty set. {} creates an empty dictionary.

Add, remove, update

MethodWhat it does
add(x)Adds one item (nothing happens if it's already there)
remove(x)Removes x; raises KeyError if it's missing
discard(x)Removes x; does nothing if it's missing
pop()Removes and returns an arbitrary item
update(other)Adds every item from another set or iterable
clear() / copy()Empty the set / make a copy
 
s = {1, 2, 3}
s.add(4)            # {1, 2, 3, 4}
s.add(4)            # still {1, 2, 3, 4}
s.remove(1)         # {2, 3, 4}
s.discard(99)       # no error, nothing changes
s.remove(99)        # KeyError: 99
s.update([7, 8])    # {2, 3, 4, 7, 8}

for item in s:      # loop with for (order is not guaranteed)
    print(item)

Set operations

Let a = {1, 2, 3, 4} and b = {3, 4, 5}.

OperationOperatorMethodResult
Union (everything)a | ba.union(b){1, 2, 3, 4, 5}
Intersection (shared)a & ba.intersection(b){3, 4}
Difference (in a, not b)a - ba.difference(b){1, 2}
Symmetric difference (in one, not both)a ^ ba.symmetric_difference(b){1, 2, 5}

Testing relationships

{1, 2}.issubset({1, 2, 3})      # True
{1, 2, 3}.issuperset({1, 2})    # True
{1, 2}.isdisjoint({3, 4})       # True  (nothing in common)

A handy trick: remove duplicates from a list

names = ['ava', 'sam', 'ava', 'lee', 'sam']
unique = list(set(names))       # 3 items; the order may change
print(len(unique))              # 3

Dictionaries

A dictionary stores key-value pairs, like a real dictionary stores words and their meanings. You look things up by key instead of by position.

  • Indexed by number
  • Duplicate keys
  • Add, update, delete
  • { key: value }
Keys must be immutable (strings, numbers, tuples). Values can be anything. Since Python 3.7 a dictionary remembers the order you inserted items, but you still can't ask for d[0].

Create and read

student = {'name': 'Ava', 'age': 12, 'grade': 7}

print(student['name'])              # Ava
print(student.get('age'))           # 12
print(student.get('school'))        # None  (no error)
print(student.get('school', 'n/a')) # n/a   (your own default)
print(student['school'])            # KeyError: 'school'
Watch out: d[key] crashes when the key is missing. d.get(key) returns None instead.

Create, read, update, delete (CRUD)

ToolsWhat it does
Create{ }, d[key] = value, setdefault(key, value)setdefault returns the value, and inserts it only if the key is missing
Readkeys(), values(), items(), get()Keys, values, or (key, value) pairs
Updateupdate(), d[key] = valueChanges a value, or adds the key if it's new
Deletepop(key), popitem()pop removes a key and returns its value; popitem removes the last inserted pair
 
student = {'name': 'Ava', 'age': 12}

student['school'] = 'Lincoln'          # add a new key
student['age'] = 13                    # change an existing value
student.update({'age': 14, 'team': 'Blue'})
print(student)
# {'name': 'Ava', 'age': 14, 'school': 'Lincoln', 'team': 'Blue'}

print(student.pop('school'))           # Lincoln  (and it's removed)
print(student.popitem())               # ('team', 'Blue')  the last pair added
print(student)                         # {'name': 'Ava', 'age': 14}

Looping

scores = {'ava': 90, 'sam': 78}

for key in scores.keys():             # or just: for key in scores
    print(key)

for value in scores.values():
    print(value)

for key, value in scores.items():     # both at once
    print(key, value)                 # ava 90, then sam 78

Counting with a dictionary

counts = {}
for word in ['red', 'blue', 'red']:
    counts[word] = counts.get(word, 0) + 1

print(counts)     # {'red': 2, 'blue': 1}
