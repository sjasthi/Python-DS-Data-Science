🎯 What are Objects and Classes?

🏭 Think of it like a Cookie Factory!

Class = Cookie Cutter - It's the template that defines what shape cookies will have

Object = The Actual Cookie - Each cookie made from the cutter is unique but follows the same pattern

In Programming Terms:

• A Class is like a blueprint that describes what something should look like and what it can do

• An Object is a specific instance created from that blueprint

🐕 Let's Create a Pet Class!

Here's how we define a class in Python:

class Pet:
    def __init__(self, name, animal_type, age):
        self.name = name
        self.animal_type = animal_type
        self.age = age
        self.happiness = 50

    def feed(self):
        self.happiness += 10
        return f"{self.name} is happy! Happiness: {self.happiness}"

    def play(self):
        self.happiness += 15
        return f"{self.name} loves playing! Happiness: {self.happiness}"

    def introduce(self):
        return f"Hi! I'm {self.name}, a {self.age} year old {self.animal_type}!"

Key Parts Explained:

• __init__ - This is the constructor, it runs when we create a new pet

• self - This refers to the specific pet object we're working with

• Methods like feed() and play() are things our pet can do

💡 Understanding the Code

Here's how we create and use pet objects:

# Creating objects from our Pet class
my_dog = Pet("Buddy", "Dog", 3)
my_cat = Pet("Whiskers", "Cat", 2)

# Using the objects
print(my_dog.introduce())  # Output: Hi! I'm Buddy, a 3 year old Dog!
print(my_cat.feed())       # Output: Whiskers is happy! Happiness: 60

🎉 What We Learned!

Classes are like blueprints that define:

• What data an object will store (attributes like name, age)

• What actions an object can perform (methods like feed, play)


Objects are individual instances created from a class:

• Each object has its own unique data

• All objects from the same class can do the same actions

• You can create as many objects as you want from one class!
