One variable, several useful descriptions.

Before choosing a chart or calculating an average, ask what the values mean.

Qualitative → categories

Names, groups, or ordered labels: pet species, school name, and satisfaction level.

Nominal has no inherent order. Ordinal has a meaningful order. Binary describes exactly two possible categories.

Quantitative → amounts

Counts or measurements: books donated, height, and elapsed time.

Discrete / continuous describes possible values. Interval / ratio describes how to interpret differences and zero.

These labels answer different questions. A book count is discrete and ratio. Celsius temperature is continuous and interval. A Pass/Fail status has two categories (binary) and can be treated as nominal labels.
