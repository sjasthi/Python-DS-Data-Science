Datetime conversion and calendar fields
pd.to_datetime converts date-like values. A datetime Series exposes .dt fields; a DatetimeIndex exposes fields directly. Weekday codes run from Monday=0 to Sunday=6.
Extract calendar fields
January 1, 2024 was Monday, so its weekday is 0.
Handle an invalid date
errors='coerce' converts invalid strings to NaT. 2024 is a leap year.
Check the datetime index
set_index moves date into the index; sorting supports chronological operations. Avoid setting the same date column twice after it has been removed.
Select dates and ranges
With the sorted DatetimeIndex, a partial month string selects all rows in that month. Label-based range slicing includes both endpoints. An exact unique timestamp selects one row.
A month and a day
January has 31 observations. Here the day selection is a row Series, not a one-row DataFrame.
Inclusive range and one-row table
The range includes six daily rows. A list of timestamps preserves a DataFrame.
Weekly aggregation
resample partitions observations into time bins; mean reduces each bin to a summary. Select the value column so calendar codes are not averaged. 'W' means weeks ending Sunday by default.
Weekly means
Weekly bins are labeled by Sunday. The final bin is partial because the series ends on Tuesday, April 9.
Inspect bin sizes
The final bin has two observations (April 8 and 9), though its label is April 14.
Resampling versus rolling
Resampling creates calendar-bin summaries; rolling creates moving overlapping windows.
Trailing rolling windows
rolling(window=7) uses seven observations. With this regular daily dataset that corresponds to seven days; irregular timestamps would differ. By default seven valid observations are needed for the mean.
Seven-observation moving mean
The first six rolling means are NaN. The seventh uses the first seven values.
Minimum observations and time windows
Integer windows default min_periods to window size; time-offset windows default to 1. '3D' uses elapsed time, not a fixed number of rows.
Previous observations and changes
shift(1) moves values down one row while keeping the index labels; diff() subtracts the previous value. Both create a missing first value. A positional lag need not represent a day in irregular data.
Lag and difference
diff equals current value minus previous value. Negative results indicate a decrease.
Predictable values and shifted timestamps
shift(1,freq='D') moves index labels by a day and keeps values attached; it is different from a positional lag.
