Grouped aggregations

Totals and multiple statistics

Titanic examples
Numeric means skip missing measurements. Missing grouping keys are excluded by default.
Custom counts and missing keys
dropna=False retains rows whose grouping key is missing.
Nested grouping: count versus survival
For observed binary Survived: count = passengers with an outcome, sum = survivors, mean = survival fraction. Key order changes the index hierarchy.
Pivot tables summarize and reshape
index defines rows, columns defines columns, values chooses the measurement, and aggfunc chooses the summary. pivot_table defaults to mean.
Department pivot
Different value columns can use different aggregation functions.
Survival rates and passenger counts
Keep missing mean cells as NaN: an absent group is not a 0% survival rate.
Boarding location and class
The first counts observed Sex values; the second sums binary survival flags. Missing Embarked keys are excluded.
Other measurements
Avoid filling absent fare averages with zero, which would imply free tickets.
Pivot versus pivot_table
pivot reshapes unique key pairs without aggregation; pivot_table can aggregate duplicates.
cut and qcut create grouping categories
cut accepts explicit edges or a number of equal-width intervals. qcut uses quantiles to target approximately equal numbers of observations.
Explicit cut boundaries
Default intervals are right-closed: (0,10] includes 10 but excludes 0. Use include_lowest=True to include 0.
Quantile bins
Each quartile here contains three observations; interval widths need not match. Tied values can prevent distinct quantile edges.
Age categories
These labels name intervals (20,30], (30,40], etc., not calendar decades: age 30 is in the first interval. observed=False includes unused categorical groups.
agg, apply, transform, and filter
agg reduces groups; apply supports flexible custom results; transform returns values aligned with the selected input; filter keeps or removes whole groups.
Custom apply with measurement columns
Select measurement columns before apply for compatibility across pandas versions. Empty groups have NaN statistics; retain those rather than implying zero salary.
Equivalent built-in aggregation
Prefer built-in agg for standard reductions; it is simpler than a custom apply.
Transform: repeat each group mean
One group mean is repeated on each corresponding input row; the result aligns with people.index.
Safe min-max normalization
The raw formula divides by zero for constant groups. Here observed constant values map to 0; missing values stay missing.
Filter groups, not individual rows
filter keeps every row in a qualifying age group, including members earning 5000 or less.
Melt and practice
melt turns measurement columns into rows while retaining identifiers. Choose a grouped summary when you need fewer rows; transform when you need row-level comparisons.
Wide to long
Ten people × two measurements = twenty rows. Age and salary share a Value column but have different units.
Reshape back
Each name/Attribute pair is unique here, so pivot is sufficient.
