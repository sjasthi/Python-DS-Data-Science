A small example with missing values
len counts all entries; count excludes missing entries.
Categorical summaries
Use counts and proportions for labels such as Embarked. Missing values are excluded by default from nunique and value_counts, but unique includes them.
Unique values and distinct counts
unique returns values; nunique returns their count. dropna=False counts missing as a distinct value.
Frequency and percentage
Default percentages use non-missing observations as the denominator. Include missing to use all rows.
Modes and missing values
mode can return multiple tied values. Selecting the first hides ties; an all-missing Series has no default mode.
Numeric summaries: center, spread, and shape
A mean alone cannot describe variability. Choose statistics that answer your question; numeric identifiers are not always meaningful measurements.
Center and counts
mean and median skip missing values by default. Median is less sensitive to extreme values.
Spread
std and var default to sample statistics (ddof=1). Range uses only the extremes.
Percentiles and IQR
IQR = Q3 − Q1. describe gives count, mean, std, min, quartiles, and max for numeric data.
Skewness and kurtosis
Positive skew indicates a longer right tail. pandas reports excess kurtosis: the normal reference is 0, not 3. Zero skew does not prove symmetry.
Zero, non-zero, and missing
For ordinary float NaN, NaN != 0 is True. Add notna() when counting observed non-zero values.
Totals, cumulative values, ranks, and custom summaries
A reduction returns a summary. Cumulative operations and rank preserve one position per input observation.
Sum and product
Products can overflow or become zero; fare product is rarely useful. min_count=1 prevents an all-missing sum becoming 0.
Cumulative operations
Cumulative values depend on row order: [2,5,9] and [2,6,24].
Ranking
Default rank assigns the average rank to ties; smaller values receive lower ranks.
Named custom aggregations
A Series agg dictionary gives readable result labels.
Flag possible outliers
The 1.5×IQR rule flags observations for investigation; it does not prove they are errors.
Row-wise summaries and axis
axis=0 reduces down rows, producing a result per column. axis=1 reduces across columns, producing a result per row.
Average related measurements
Select the original subjects explicitly so repeated runs do not average a previously created summary.
Column versus row means
Titanic row means mix age, fare, identifiers, and codes. They are executable but lack a meaningful shared unit.
Summaries of the whole DataFrame
Check dimensions and missingness first. Select meaningful numeric columns before interpreting statistics or correlations.
Dimensions and completeness
size counts all cells, including missing ones. Missing percentage is the mean of a boolean indicator ×100.
Numeric summaries
numeric_only avoids trying arithmetic on text columns; numeric codes still require judgment.
Categories, correlation, cumulative values
Correlation uses paired non-missing observations and does not imply causation. Mode may have ties.
