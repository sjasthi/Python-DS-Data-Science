Select one column or several
A single column selected by name is a Series. A list of names returns a DataFrame, even when the list contains only one name.
Series vs DataFrame

Bracket vs attribute access
Prefer brackets: names with spaces and names that collide with methods are supported.
Labels, positions, slices and scalar cells
loc uses row and column labels. iloc uses zero-based positions. Label slices include the stop label; positional slices exclude the stop position. Both work with the default integer index.
Slice endpoints and steps
Practice: select positions 2, 4, 6, 8 using a stepped slice.
Labels can differ from positions
loc[200] and iloc[1] select the same row here.
Cells and rectangles
at and iat access a scalar by label and position respectively.
Safe assignment on a copy
Avoid chained assignment such as df[1:3]["Age"] = 5; use one loc operation.
Keep rows that meet conditions
A boolean mask contains True for rows to keep. Use & for AND, | for OR and ~ for NOT; put parentheses around each comparison. For the standard CSV, a missing Age does not pass Age > 70.
One condition and selected columns
Practice: select names and ages of passengers younger than 10.
AND, OR and membership
isin([1, 3]) tests whether each value belongs to the list.
query with a variable
Inside a query string, and is allowed and @ refers to a Python variable.
Visit rows and columns
Use vectorized column operations first. When a loop is useful, iterrows yields an index label and a Series; itertuples yields named tuples and is usually faster. Do not assume iterrows preserves every column dtype.
By label and by position
Use labels with loc and positions with iloc.
iterrows and itertuples
Tuple field names may be renamed for invalid identifiers; Name and Age are valid here.
Traverse columns
Use items(), not the removed iteritems(). Iterating df directly yields column labels.
Vectorized alternative
Column operations usually avoid the need for a Python row loop.
Custom conditions and random samples
Keep the original df available. A separate scores_df prevents later Titanic examples from failing because their columns disappeared.
Custom row filter
axis=1 applies the function to each row. A simple condition is easier to vectorize.
Random rows and columns
axis=0 selects rows; axis=1 selects columns. random_state makes a sample reproducible.
