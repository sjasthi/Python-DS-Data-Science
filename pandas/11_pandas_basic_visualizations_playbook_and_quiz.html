Inspect one series
DataFrame plots often display several columns; a Series plot displays one selected column.
Compare observations
Line plots connect ordered observations, making them useful for time trends. Bar plots compare values at discrete positions. Neither automatically computes category frequencies.
Line plot
The index supplies the horizontal axis; each numeric column becomes a line.
Grouped bar plot
Each date has five bars. Plotting raw numeric columns displays their values, not frequency counts.
Actual category frequency bars
Compute value_counts first when you want a frequency bar chart.
Series methods
df.plot.line() is a convenient alternative to df.plot(kind='line').
Inspect numeric distributions
Histograms count numeric observations in intervals; they do not preserve time order. Box plots summarize median, quartiles, spread, and potential outliers.
Histogram
Bin choices affect appearance. Overlapping histograms need transparency or separate panels.
Single-series histogram
The counts across bins total ten observations for this complete Series.
Box plot
The box spans Q1 to Q3; the line marks the median. Default whiskers extend to extreme observations within 1.5×IQR fences; plotted fliers are candidates for investigation.
Filled and stacked areas
Area plots fill the region under each series. DataFrame area plots are stacked by default, so the top boundary represents a sum. These positive synthetic values permit stacking, but an additive interpretation needs meaningful compatible units.
Default stacked area
The height of the uppermost boundary is the sum of all five columns at that date.
Unstacked and single-series areas
Unstacked areas overlap instead of accumulating. Series area plots show one measurement.
Compare two numeric variables
Scatter plots use one numeric column for x and another for y. Each point is one row, so this plot compares A with B rather than using dates as the horizontal axis. A pattern does not establish causation.
A versus B
Specify x and y for a scatter plot. The two columns should represent measurements worth comparing.
Scatter method and point style
s controls marker area and alpha controls transparency.
Plot size, labels, and method shortcuts
Pandas uses matplotlib here. figsize sets width and height in inches for an individual figure; rcParams changes defaults for later figures. Clear labels and appropriate chart selection matter more than decoration.
Set a figure size
figsize=(12,6) means 12 inches wide and 6 inches high; screen pixels depend on DPI.
