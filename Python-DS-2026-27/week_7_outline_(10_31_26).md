## 📚 Topics Covered Today

### [1] Introduction to GitHub
**Store your code, track changes, and share your projects**

📊 [Reference: Introduction to GitHub](https://github.com/sjasthi/Python-DS-Data-Science/blob/main/Presentations/introduction_to_github.md)

**Key Learning Objectives:**

- Explain the difference between Git and GitHub.
- Understand repositories, commits, cloning, pushing, and pulling.
- Practice the workflow: **clone → edit → commit → push → pull**.
- Understand how GitHub Pages can publish a portfolio website.

### [2] Introduction to VS Code
**Your workspace for building applications**

💻 [Reference: Introduction to VS Code](https://github.com/sjasthi/Python-DS-Data-Science/blob/main/Presentations/introduction_to_vscode.md)

**Topics Covered:**

- Install and explore VS Code and Git.
- Open a project folder and use the Explorer, editor, terminal, and Source Control panel.
- Sign in to GitHub and clone a repository.
- Edit files, review changes, commit, and push from VS Code.

### [3] GitHub Copilot (GHCP)
**Use AI to build, understand, and improve your work**

**Key Learning Objectives:**

- Enable GitHub Copilot in VS Code using the class guide.
- Ask focused questions to create or improve HTML and CSS.
- Ask Copilot to explain code and help troubleshoot problems.
- Review, personalize, and test suggestions before accepting them.
- Document what you asked, what you changed, and how you checked the result.

### Hands-on Practice: Start Your Portfolio

1. Create or open your **YOUR-USERNAME.github.io** repository.
2. Clone it and open the project in VS Code.
3. Begin an `index.html` page and a `style.css` file.
4. Add a short introduction and outline your About Me, Skills, and Projects sections.
5. Ask Copilot to explain or improve a small part of your page.
6. Preview your changes, make a meaningful commit, and push to GitHub.
