**Class date:** Saturday, November 7, 2026

**Two-week unit:** Weeks 8 and 9 — Excel or Google Sheets

## 📅 Overview

This week we begin using spreadsheets to explore and analyze data. You may use **Microsoft Excel or Google Sheets** throughout this unit and for Assignment 6. Both paths develop the same core data analysis skills.

Week 8 emphasizes foundations and data exploration. Week 9 adds multi-criteria analysis, text functions, PivotTables, charts, and assignment completion.

## 🎯 Learning Objectives

By the end of this week, you should be able to:

- Navigate a spreadsheet and import a CSV dataset.
- Understand rows, columns, headers, data types, and cell references.
- Use relative and absolute references.
- Calculate summaries with COUNT, COUNTA, COUNTIF, SUM, AVERAGE, MIN, and MAX.
- Identify missing data and distinguish numeric counts from non-empty counts.
- Sort and filter records while preserving row integrity.
- Begin answering the Titanic assignment questions using formulas.

### Hands-on Practice

1. Import the Titanic dataset and inspect its columns.
2. Count passengers, survivors, and passengers in each class.
3. Identify missing ages and cabin values using bounded data ranges.
4. Sort a working copy by fare and filter by passenger class.
5. Create an Answers sheet and record the question number, formula, and result.

## 💡 Practice and Data Quality

- Preserve the original dataset; use a working copy and separate helper columns.
- Keep entire rows together when sorting.
- Exclude the header from calculations.
- Use ranges ending at the last passenger row when counting blanks. An open-ended range can count unused rows as missing data.
- Distinguish missing ages from zero ages; do not replace missing values with zero just to simplify calculations.
- Check whether percentages are stored as fractions formatted as percentages or multiplied by 100; avoid doing both.
- Show formulas and label answers by question number.
- Use assignment hints, built-in function help, and class discussions when you get stuck.
