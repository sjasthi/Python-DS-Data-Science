### **Objective:**
Know exactly where everything lives and how to submit your work.

### **Course GitHub Repository:**
- Link: https://github.com/sjasthi/Python-DS-Data-Science
- Folders you'll use all year:
  - `Weekly_Planner` — the full-year schedule
  - `Outlines` — weekly plans like this one
  - `Presentations` — class slides and reference material
  - `Assignments` — weekly assignments

### **Tools You'll Need:**
- A Google account (for Google Classroom and Google Colab)
- **Google Colab** (https://colab.research.google.com/) — where you'll run Python notebooks, no installation needed
