## 1. Pandas – Reading and Writing Files

Learn how to load data from files into DataFrames and export processed data for later use.

### Topics

- Explore common data sources and file formats.
- Read data from CSV, Excel, and other formats demonstrated in the notebook.
- Inspect loaded data for column names, data types, and missing values.
- Modify a DataFrame and save the updated data to a file.
- Compare input and output formats and verify that exported files contain the expected data.
