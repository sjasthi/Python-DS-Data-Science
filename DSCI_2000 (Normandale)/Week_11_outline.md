## 1. Pandas – cut, qcut, apply, transform, and filter

Learn how to categorize numerical data, apply custom functions, transform values, and filter groups using pandas.

### Topics

- Create bins using `pd.cut()` with equal-width intervals or custom boundaries.
- Create quantile-based bins using `pd.qcut()` and compare the results with `cut()`.
- Apply custom functions using `apply()` and understand the `axis` parameter.
- Use `transform()` to return results aligned with the original data.
- Filter groups using `groupby().filter()` based on group-level conditions.
- Explore the notebook’s additional reshaping and summary tools: `melt()`, `stack()`, and `crosstab()`.
